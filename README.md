# Energy Lab — PWA v10.0.1

Energy Lab — local-first PWA для назірання за энергіяй, нагрузкай, аднаўленнем і тым,
якія тыпы дзён/актыўнасцей пакідаюць больш рэсурсу.

## Версія

**v10.0.1**

Гэта PWA-зборка генеруецца з асобнай standalone-версіі
`energy-lab-v10-clean.html`. Яна не базіруецца на папярэднім PWA-архіве.

## Што ёсць у актуальнай версіі

### Energy
- Energy 0–10 можна адзначаць некалькі разоў на дзень.
- Значэнне заўсёды адносіцца да стану **ў канкрэтны момант**, а не да ацэнкі ўсяго дня.
- На дзённым графіку Energy паказваецца па часе.

### Працоўны дзень
Адзін chip `💼 Праца` на дзень.

Яго можна запаўняць паступова:
- дома / офіс / змешана;
- Energy перад працай;
- колькасць розных працоўных кантэкстаў;
- колькасць працоўных размоў;
- Energy пасля працы.

Пасля захавання chip паказваецца як ужо выбраны і адкрывае той жа запіс для рэдагавання.

`Офіс` не з'яўляецца асобнай падзеяй.

### Падзеі і актыўнасці
Ёсць, сярод іншага:
- размова;
- спатканне;
- літоўская;
- хобі;
- шпацыр;
- ровар;
- workout;
- серыял/фільм;
- аднаўленне;
- лекар/лякарня;
- стрэсавая падзея;
- іншае.

Падзеі дадаюцца **постфактум**. Start/Stop таймера няма.
Калі працягласць мае сэнс, выбіраецца прыкладны час.

### Фізічныя актыўнасці
Для шпацыру, ровара і workout пасля можна асобна ацаніць 0–10:
- Energy пасля;
- фізічны стан;
- ментальны стан;
- задавальненне ад актыўнасці.

### Іншыя актыўнасці
Follow-up выкарыстоўвае шкалу 0–10 для:
- Energy пасля;
- задавальнення ад актыўнасці.

### Аднаўленне
Аднаўленне — наўмыснае памяншэнне нагрузкі для вяртання рэсурсу.
Для яго паказваюцца рэлевантныя спосабы/тэгі, напрыклад:
- цішыня;
- цемра;
- ляжаць;
- музыка;
- душ.

### Тэгі і ўласныя катэгорыі
- Можна ствараць свае катэгорыі.
- Можна ствараць свае тэгі.
- Формы паказваюць толькі рэлевантныя тэгі, а не адзін глабальны набор для любой падзеі.

### Сон
Можна адзначаць:
- колькі гадзін спала;
- ці прачнулася выспанай.

### Рэйтынг дня
На наступны дзень прыкладанне прапануе паставіць **учорашняму дню 0–10**.

Гэта не рэйтынг прадуктыўнасці, а агульная ацэнка таго,
наколькі добра прайшоў дзень з пункту гледжання стану, нагрузкі,
прыемных рэчаў і рэсурсу.

### Графік дня
Па часе паказваюцца:
- Energy check-ins;
- падзеі/актыўнасці.

### Графік тыдня
Для кожнага дня паказваюцца:
- ранішняя Energy;
- вечаровая Energy;
- сумарна “з'едзеная” Energy;
- сумарна “вернутая” Energy;
- рэйтынг дня 0–10.

“З'едзена” — сума ўсіх падзенняў паміж паслядоўнымі Energy check-in'амі.
“Вернута” — сума ўсіх ростаў паміж імі.

### Даныя
- Даныя захоўваюцца лакальна ў браўзеры.
- Backend і лагін не патрэбны.
- Ёсць JSON export/import.
- Ёсць CSV export.

## Service worker у v10.0.1

У гэтай зборцы service worker спецыяльна абноўлены так, каб старая PWA не заставалася
праз cache:

- cache name: `energy-lab-10.0.1`;
- `skipWaiting()` пры install;
- `clients.claim()` пры activate;
- пры activate выдаляюцца **ўсе** старыя caches з прэфіксам `energy-lab-`;
- рэгістрацыя выкарыстоўвае `updateViaCache: "none"`;
- service worker рэгіструецца як `sw.js?v=10.0.1`;
- пасля рэгістрацыі выклікаецца `registration.update()`;
- navigation requests выкарыстоўваюць network-first.

Гэта азначае, што пасля новага deploy браўзер павінен забраць новую зборку,
а стары app-shell cache будзе выдалены новым worker.

## Deploy на GitHub Pages

1. Распакуй ZIP.
2. Загрузі **ўсе файлы з кораня архіва** ў корань GitHub repository.
3. GitHub → `Settings` → `Pages`.
4. `Deploy from a branch`.
5. Branch: `main`.
6. Folder: `/(root)`.
7. Адкрый HTTPS URL GitHub Pages.

## Абнаўленне ўжо ўсталяванай PWA

Пасля замены файлаў на GitHub Pages:
1. Адкрый Energy Lab пры наяўнасці інтэрнэту.
2. Пачакай некалькі секунд.
3. Аднаві старонку адзін раз.

Новы worker мае іншы version/cache ID і сам выдаляе старыя Energy Lab caches.

Калі Android усё роўна доўга трымае старую installed PWA, поўнае закрыццё прыкладання
і паўторнае адкрыццё павінна дазволіць новаму worker узяць кантроль.
